## ⚡ المميزات الهندسية والفنية | Key Features
1. **محرك السائل التوليدي (Three.js & Custom GLSL Shaders):**
   - خوارزمية تشويه السطح ثلاثية الأبعاد عبر دالة **Simplex 3D Noise**.
   - تفاعل فيزيائي فوري مع حركة الفأرة واللمس يطلق موجات ارتدادية وصدمات حركية دائرية متوسعة.
   - 5 خامات طيفية حصرية سائلة:
     - **الكروم السائل المصقول (Molten Chrome)**
     - **اللؤلؤي النيون المتوهج (Neon Iridescent Pearl)**
     - **الذهب المنصهر عيار 24 (24K Molten Gold)**
     - **زمرد الأعماق المتألق (Bioluminescent Deep Sea Emerald)**
     - **مرآة الأوبسيديان البركانية (Obsidian Mirror)**
   - سرب جسيمات كمومية أثيرية (Quantum Swarm) بأكثر من 2400 جسيم مضيء يسبح حول الكتلة السائلة ويتفاعل مع ترددات الصوت.

2. **معمل السِنث الإجرائي والموزع الإيقاعي (Web Audio API):**
   - محرك تركيبي متعدد الترددات (Polyphonic Dual-Oscillator FM/Subtractive Synth) فوري بدون أي ملفات صوتية خارجية.
   - مرشحات تفاعلية ونظام صدى وانعكاس فضائي (Algorithmic Convolver Reverb).
   - 4 مقامات وسلالم موسيقية حية:
     - **مقام الحجاز الأصيل (Hijaz Arabic Scale)**
     - **مقام البياتي العريق مع ربع التون (Bayati Heritage)**
     - **الخماسي السيبراني (Cyber Pentatonic)**
     - **الأثيري الكوني (Celestial Ambient Lydian)**
   - موزع إيقاعي حركي بـ 16 خطوة و4 مسارات صوتية قابلة للبرمجة مع تحكم بالسرعة (BPM).
   - محرك أثيري توليدي (Ambient Engine) يعزف مقطوعات تأملية ذاتية التطور لا نهائياً.

3. **واجهة تحكم فائقة الفخامة (Glassmorphism HUD):**
   - تصميم زجاجي فاخر مع تدرجات ضوئية ودعم كامل ومزدوج للغتين العربية (افتراضياً) والإنجليزية.
   - محلل طيفي حقيقي (Real-time Audio Spectrum FFT Canvas) يعرض ذبذبات الصوت وتردداته.
   - أداة التقاط فائقة الدقة بدقة **4K Ultra-HD (3840x2160)** مع علامة مائية فنية وتأثيرات احتفالية.

## ⌨️ اختصارات لوحة المفاتيح | Keyboard Controls
- **[A] إلى [K]**: عزف نغمات السلم الموسيقي النشط في الوقت الفعلي.
- **[Space]**: تشغيل / إيقاف الموزع الإيقاعي (Sequencer).
- **[F]**: إخفاء / إظهار واجهة التحكم للدخول في نمط العرض البصري الخالص (Fullscreen Canvas).
- **[P]**: التقاط لوحة فنية فائقة الدقة 4K وحفظها كملف PNG.
